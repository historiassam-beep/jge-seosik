# 출처·사진 확인 절차

1. 인터넷이 되는 PC에서 `node tests/verify-sources.js` → 열리지 않는 URL을 찾는다.
2. 출처마다 원문을 열어 `data/places.js`의 해당 사실(facts)과 대조한다.
   - 맞으면 `data/sources.js`의 `checkedAt`을 `YYYY-MM-DD`로 고친다.
   - 다르면 문장을 고치고 등급을 PROBABLE로 낮춘다. 확인 못 한 내용은 지어내지 않는다.
3. 사진은 원문 페이지에서 **이미지 주소·촬영연도·이용조건(공공누리 유형 등)** 을 확인한 것만 `photos`에 넣는다.
   - 공공누리 4유형(변경금지)은 크롭·합성 금지(앱은 `object-fit: contain`).
   - 표지석·현재 사진을 과거 사건 사진으로 표시하지 않는다(`type`: historical/current/trace).
4. `node tests/check-data.js`로 점검, `tests/e2e.js`로 화면 점검.
