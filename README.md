# 전남광주 서식 꾸러미

전남광주통합특별시교육청 **공개 게시판**에 흩어진 학교 업무 서식을 한곳에서 찾는 비공식 모음입니다.
파일은 올려 두지 않고 원문 게시판으로 연결합니다. 로그인이 필요한 자료실은 바로가기만 안내합니다.

사이트: https://historiassam-beep.github.io/jge-seosik/

## 파일 구성

| 파일 | 하는 일 |
|---|---|
| `index.html` | 사이트 화면 (검색·분류·적용 지역 필터) |
| `data/seosik.csv` | **서식 목록** — 여기만 고치면 사이트에 반영됩니다 |
| `data/boards.csv` | 하단 "서식이 올라오는 게시판" 목록 |
| `scripts/check.py` | 서식 목록 점검 (빈 칸, 잘못된 값, 중복) |

## 서식 추가하는 법

1. GitHub에서 `data/seosik.csv` → 연필(✏️) 버튼, 또는 엑셀로 열어 편집
2. 맨 아래에 한 줄 추가
3. Commit → 1~2분 뒤 사이트 반영

엑셀로 저장할 때는 **CSV UTF-8(쉼표로 분리)** 형식을 권장합니다. 일반 CSV로 저장해도 읽히게 해 두었습니다.

### 칸 설명

| 칸 | 쓰는 법 | 예 |
|---|---|---|
| 분류 | 아래 분류 중 하나 (새 이름을 쓰면 새 분류가 생김) | 교육과정·학사 |
| 서식명 | 게시판에 올라온 제목 그대로 | 수업일수 감축 운영 보고서 |
| 기관 | 서식을 올린 기관 | 광주서부교육지원청 |
| 게시판 | 게시판 이름 | 정보공개 자료실 |
| 게시일 | YYYY-MM-DD (모르면 비움) | 2026-09-17 |
| 파일형식 | 여러 개면 `/`로 구분 | hwp/pdf |
| 공개여부 | `open`(누구나) 또는 `login`(로그인 필요) | open |
| 적용지역 | `공통` / `구 광주` / `구 전남` | 구 전남 |
| 원문주소 | 게시물 주소 (없으면 게시판 주소) | https://… |
| 메모 | 교사에게 도움 되는 한 줄 | 8월 기준 최신판 |

분류: 교육과정·학사, 진로·입학, 정보·개인정보, 학생·장학, 급식·보건, 민원·대외, 교원인사·복무, 학교행정·회계, 업무 매뉴얼(통합)

### 적용지역 기준

- **공통**: 법령·교육부 지침 기반이라 지역과 상관없는 서식 (휴·복직, 호봉, 생활기록부 등)
- **구 광주 / 구 전남**: 통합 이전 각 교육청 지침이 아직 따로 적용되는 서식 (교육과정 편성, 고입 전형 등)

## 점검하기

```
python scripts/check.py
```

## 지켜야 할 것

- 로그인 뒤에서 받은 파일은 이 저장소에 올리지 않습니다
- 서식 파일 자체를 올리지 않고 원문 주소만 연결합니다
- 화면의 "교육청 공식 사이트가 아님" 문구를 유지합니다
